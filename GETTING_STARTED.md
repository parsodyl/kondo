# Getting Started 📥

Kondo is first and foremost an **architecture pattern**—a set of rules and conventions for organizing Flutter features. This package provides the foundational classes and utilities that make implementing the pattern straightforward.

## Installation

Add Kondo to your `pubspec.yaml`:

```yaml
dependencies:
  kondo: ^0.0.2
```

Kondo depends on the [hako](https://pub.dev/packages/hako) state management package, which provides the core state container primitives (`register`, `get`, `set`) that Kondo builds upon. It will be installed automatically as a transitive dependency.
